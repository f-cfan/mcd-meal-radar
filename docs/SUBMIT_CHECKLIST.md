### 项目简介参考文本

```
每天饭点主动来找你 —— 基于麦当劳官方 MCP 的定时优惠与营养搭配提醒助手。

现有的 MCP 消费类工具几乎都是「你问，它答」。本项目做成「它定时来找你」：
每日四档任务（09:00 自动领券 / 11:00 午餐 / 16:30 晚餐 / 20:00 过期提醒），
检索优惠券与门店活动，输出省钱且营养达标的搭配建议，推送到用户自配邮箱。

四层约束引擎依次求解，每条建议都附带「为什么」与「注意什么」：
偏好层（历史订单画像）→ 钱包层（券组合枚举）→ 身体层（热量/钠上限）→ 活动层（门店活动提示）。

两条不可妥协的纪律：
1. 枚举与计价严格分离 —— 金额只来自 calculate-price 真实返回，查不到就标注
「未核价」，绝不用模型估算或标签价推算。
2. 只推荐，不下单 —— 不调用 create-order 等下单类工具。官方 33 个 Tool 中
本就没有支付工具，create-order 仅返回支付链接。本项目尊重这一边界，
把决策做到「就差你确认」。

一个容易被忽视但必然遇到的问题：官方未公布 MCP Token 有效期天数，实测无 Token
时端点直接拒绝。一次性 Skill 跑完即结束天然碰不到，定时任务每天跑必然遇到。
本项目实现了完整降级链路 —— 检测到 401 立即发「需要重新授权」邮件并附缓存快照，
把必然发生的断点做成被设计过的体验，而不是静默失败。

工程实践：demo.py 零依赖、零 Token、不联网，30 秒跑通四条链路；
117 个单测覆盖单位换算（官方 calculate-price 返回「分」而 query-meals 返回「元」，
混用会差 100 倍）、场景参数矩阵、字段缺失语义；CI 在 3 个 Python 版本上跑测试并
校验参赛声明 SHA256 与官方一致。
```
